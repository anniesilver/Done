# Assets

## Icon Files Needed

The following PNG files need to be created from Logo.svg:

1. **icon.png** (1024x1024) - App icon for iOS/Android
2. **splash.png** (2048x2048) - Splash screen
3. **adaptive-icon.png** (1024x1024) - Android adaptive icon
4. **favicon.png** (48x48) - Web favicon

### How to Generate:
Convert Logo.svg to PNG format using:
- Online tool: https://cloudconvert.com/svg-to-png
- Or use ImageMagick: `convert Logo.svg -resize 1024x1024 icon.png`

### Temporary Workaround:
For initial development, you can use placeholder PNGs or run the app on web which can use SVG.
